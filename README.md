# ComponentHub

A tracking web-based system/application for electronics borrowing, logging, and inventory for managing lab hardware checkouts, returns, and condition tracking.

## Current Features
- Role Based Access Control (RBAC): Separate webpages for Admin (Restocking, Borrowing log view, CSV exports) and Students (Component Borrowing & Browsing, and Personal Return Tracking).
- Checkout & Return Tracking: Real Time tracking of borrowed components & returned components.
- Return Condition Tracking: Students can set the quality/condition of the component to be tracked by the Admins.
